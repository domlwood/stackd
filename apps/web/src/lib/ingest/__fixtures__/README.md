# Listing fixtures

`rightmove-synthetic-*.html` are **synthetic** pages modelled on Rightmove's embedded
`window.PAGE_MODEL` data. They are not real listings.

To verify the parser against the live page structure, save a real listing
("Save Page As… → Web Page, HTML only") here as `rightmove-real-1.html` and
`rightmove.test.ts` will pick it up automatically.
